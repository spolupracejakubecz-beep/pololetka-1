# Pololetka 1.P – Ekonomika, Právo, Účetnictví

Studijní web na pololetní zkoušky (Střední škola Spektrum, 1.P, 1. pololetí).

- `index.html` – plán učení do 3. 12. a odpočet do zkoušky
- `ucivo.html` – výtah učiva (vygenerováno z `_zdroj/vytah.md` skriptem `_zdroj/build_ucivo.py`)
- `trenink.html` – kvíz s vysvětlením, kartičky, zkouška nanečisto
- `hra.html` – kvízová hra jako Kahoot: sólo, nebo hra přes PIN, kde se každý připojí ze svého zařízení (PeerJS, bez vlastního serveru)
- `data.js` – otázky a kartičky

Čistě statický web, bez buildu. Nasazení: Vercel → Add New Project → import tohoto repozitáře → Deploy.
